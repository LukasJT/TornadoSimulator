How version one works

While this app is open, it refreshes official warnings every 60 seconds and displays a local notification once for each new alert. The notification opens this status screen.

Background alerts are next

Reliable alerts while the app is closed require a push service. Until that backend is deployed, keep Wireless Emergency Alerts enabled and never use this app as your only warning source.
