安徽的龙卷风

安徽地处江淮平原，是中国龙卷风较多的省份之一。夏季强对流频繁，历史上曾出现造成伤亡的强龙卷。

概览

地区江淮平原、皖北、沿江
季节夏季（6–8 月）
主管安徽省气象局

为何安徽多发？

安徽位于长江与淮河之间的平原地带，地势平坦，夏季受强对流天气影响大，加上暖湿气流活跃，为龙卷风提供了条件。皖北与沿江地区相对多发。

历史事件

安徽多地曾记录到龙卷风，个别达到较强等级并造成人员伤亡和农田、房屋损失。多数仍为 EF0–EF2。

预警

安徽省气象局在强对流天气下发布预警。参阅 避险指南 与 龙卷风季节。

来源

  • 安徽省气象局
