How does an explicit diffusion step smooth a modeled cloud field?

Tornado Hub · Lesson · Applied math · introductory numerics · November 21, 2026

An explicit diffusion step moves a modeled scalar toward the average of its neighboring values. The stencil approximates the second spatial derivative.

Worked example

Use qnew = qi + μ(qleft−2qi+qright), where μ = KΔt/Δx². For neighbors zero and centre eight, μ = 0.10 gives 8−1.6 = 6.4. This example uses a uniform one-dimensional grid and constant diffusivity. For the standard explicit stencil the stability limit is μ ≤ 0.5.

Practice questions

  1. If all three values equal eight, what is the update?
  2. Halve grid spacing at fixed K and time step. What changes?

Worked answers

Answer 1

The second difference is zero, so the value remains eight.

Answer 2

μ quadruples to 0.40. This is still within the stated one-dimensional stability limit.
