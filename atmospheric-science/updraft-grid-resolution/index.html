How many grid cells resolve a simulated supercell updraft?

Tornado Hub · Lab · Storm modeling · upper undergraduate · November 21, 2026

Divide the physical width of an updraft by grid spacing to estimate how many nominal cells span it. Use a refinement comparison to examine whether its structure is resolved.

Start with How much memory does a three-dimensional supercell grid require?.

Set up the experiment

Keep the updraft width fixed at 3 km. Predict how the number of cells changes when spacing is quartered. At 1 km spacing the width spans three nominal cells. At 250 m it spans twelve. Actual samples inside depend on grid alignment. To test resolution, refine again while retaining comparable physics, and compare width, peak w and track over the same period.

Practice questions

  1. How many nominal cells are across at 500 m spacing?
  2. Does a count of twelve prove the updraft is resolved?
  3. How should you compare simulated peak w across the runs?

3,000/500 = 6.
