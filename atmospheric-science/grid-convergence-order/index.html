How do you measure numerical convergence in a storm simulation?

Tornado Hub · Lesson · Applied math · introductory numerics · November 21, 2026

Estimate convergence order by comparing a consistent error metric as grid spacing decreases. For successive grid halvings, take the base-two logarithm of the error ratio.

Worked example

If error behaves like CΔxᵖ, halving Δx reduces error by 2ᵖ. Errors 0.8, 0.2 and 0.05 each decrease by a factor of four, giving p = 2. Use a trusted reference and keep the comparison time and physical problem fixed. Other error sources can dominate at some resolutions.

Practice questions

  1. What order corresponds to error shrinking by a factor of two each time?
  2. What does an increasing error after refinement suggest?

log₂2 = 1.
