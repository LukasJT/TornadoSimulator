Why do saved output times change estimated storm peak intensity?

Tornado Hub · Lab · Storm modeling · upper undergraduate · November 21, 2026

Coarse output intervals can miss the strongest simulated updraft even when the model integrates every event internally. Diagnose the sampling effect by thinning output from one run.

Start with How do you track an updraft centroid in model output?.

Set up the experiment

Use the same five minute-by-minute values in both samples. Predict what happens when only minutes 0 and 4 are retained. The full series peaks at 31 m/s at minute 2. The sparse output reports a maximum of 12 m/s, 19 m/s below that sampled peak. Neither record establishes the maximum between its own output times.

Practice questions

  1. Save at minutes 0, 2 and 4. What maximum survives?
  2. Save at minutes 1 and 3. What maximum survives?
  3. Does this experiment change the numerical solution?

Worked answers

Answer 1

31 m/s, because the sampled peak is retained.

Answer 2

19 m/s, which misses the sampled peak by 12 m/s.

Answer 3

No. Thinning the saved values changes the available diagnostics while leaving the original run unchanged.
