Gradient Richardson number practice for a sheared inflow layer

Tornado Hub · Practice set · Atmospheric science · dynamics · November 21, 2026

The gradient Richardson number compares stabilizing stratification with vertical wind shear. Use the squared magnitude of the vertical wind gradient in the denominator.

Start with Why does baroclinicity generate vorticity along storm outflow?.

Advertisement

Worked example

Use Ri = N²/[(du/dz)²+(dv/dz)²]. At N² = 10⁻⁴ s⁻² and wind gradients of 0.02 and 0 s⁻¹, the denominator is 0.0004 s⁻² and Ri = 0.25. The value is local and dimensionless. A textbook shear-instability threshold applies under specific flow assumptions.

Practice questions

  1. Find the squared shear magnitude in the example.
  2. Find the Richardson number.
  3. Double the eastward shear gradient while holding everything else fixed.
  4. Use two gradients of 0.02 s⁻¹ with original N².
  5. A student divides by 0.02 s⁻¹. Identify the dimensional error.
  6. What if the vertical wind gradient vanishes?

Worked answers

Answer 1

0.02² = 0.0004 s⁻².

Answer 2

0.0001/0.0004 = 0.25.

Answer 3

The denominator quadruples, reducing Ri to 0.0625.

Answer 4

The denominator is 0.0008 s⁻² and Ri = 0.125.

Answer 5

Both numerator and denominator must be in s⁻². Square the gradient magnitude first.

Answer 6

The stated ratio has zero denominator. Do not interpret that result as finite Ri.
