How do you initialize a warm bubble in an idealized supercell model?

Tornado Hub · Lab · Storm modeling · upper undergraduate · November 21, 2026

An idealized warm bubble initializes buoyancy by adding a smooth potential-temperature perturbation around a chosen centre. Its radius, amplitude and shape affect the initial lift.

Start with How many grid cells resolve a simulated supercell updraft?.

Set up the experiment

Set a two-kelvin peak and a radius R. At distance r inside R, use Δθ = 2cos²(πr/2R) K. Outside R set the perturbation to zero. Predict where the shell first reaches one kelvin, then calculate the centre, halfway point and edge. This analytic bubble is the assigned exercise shape. Check a model’s documented dimensions and initialization before using a similar perturbation there.

Practice questions

  1. Find the perturbation at R/4.
  2. Double the amplitude without changing radius. What happens halfway out?
  3. What happens if the grid is too coarse to sample the interior well?

Worked answers

Answer 1

2cos²(π/8) ≈ 1.71 K.

Answer 2

The perturbation doubles to 2 K.

Answer 3

The initialized peak and effective shape can differ from the analytic specification. Compare the sampled field across resolutions.
