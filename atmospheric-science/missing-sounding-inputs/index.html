How do you reproduce a simulator result from a sounding with missing inputs?

Tornado Hub · Lab · Storm modeling · algebra and sensitivity · November 21, 2026

Reproducing a fixed-layer STP requires all four inputs and their layer definitions. With surface-based CAPE, cloud base and 0–6 km shear supplied, the remaining input is 0–1 km storm-relative helicity.

Start with How much latent heat is released as water condenses inside an updraft?.

Set up the experiment

Start with the same supplied sounding summary for all runs. Predict which values can be reconstructed with no additional observations. CAPE, shear and LCL are available by assumption. For SRH, obtain the vertical wind vectors through the first kilometre above ground and choose or estimate storm motion. Integrate the storm-relative hodograph with consistent sign and units. Until then report the index as unavailable. Filling the field with zero would represent an explicit physical input and force the product to zero.
