How does storm-motion error shift a supercell track forecast?

Tornado Hub · Lab · Physical science · vectors · November 21, 2026

For equal travel distances and an angular track error, cross-track miss distance is the travel distance times the sine of the heading difference. A small angle matters more at longer lead times.

Start with How far will a moving supercell travel between two radar scans?.

Set up the experiment

Fix a flat local map and measure cross-track distance perpendicular to the predicted straight track. Use the same speed and starting point for both paths. Before calculating, predict which lead time produces the larger miss. If a storm travels L = 60 km on a course 10° off the prediction, |cross-track miss| = 60 sin 10° ≈ 10.4 km. This isolates heading error. Speed error, changing storm structure and curvature can add other displacement components.

Practice questions

  1. If the storm travels 60 km at 5° off the predicted heading, find the miss.
  2. At 60 km and 10°, how far along the predicted axis has the storm traveled?
  3. What if the heading is correct but speed differs?

Worked answers

Answer 1

60 sin 5° ≈ 5.23 km.

Answer 2

60 cos 10° ≈ 59.09 km, about 0.91 km short of the predicted endpoint along that axis.

Answer 3

Cross-track error from heading is zero. The endpoints can still differ along the predicted axis.
