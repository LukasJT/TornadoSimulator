How do you decode sea-level pressure from a station plot?

Tornado Hub · Practice set · Environmental science · measurement · November 21, 2026

The common three-digit sea-level pressure code gives the last three digits of pressure in tenths of a hectopascal. Restore the omitted digits using the expected pressure range.

Start with What does an infrared brightness temperature tell you about a storm top?.

Advertisement

Worked example

In the usual near-1,000 hPa station-plot convention, for a code below 500 add 1,000 to its value divided by ten. For codes 500 and above add 900. Thus 127 becomes 1012.7 hPa and 987 becomes 998.7 hPa. In exceptional conditions, use the surrounding analysis or full observation to resolve ambiguity.
