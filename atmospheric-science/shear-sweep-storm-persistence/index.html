How does changing wind shear alter idealized storm organization at fixed buoyancy?

Tornado Hub · Lab · Storm modeling · upper undergraduate · November 21, 2026

To isolate wind shear in an idealized storm experiment, keep the buoyancy profile and other model choices fixed and change only the prescribed shear. Compare both runs using the same criterion for a persistent rotating updraft.

Start with How do you check water-mass conservation in a cloud model?.

Set up the experiment

Use a common grid, initial trigger, microphysics and output frequency. Predefine a time-contiguous persistence threshold for the rotating updraft. In the assigned comparison, the tracked cores last 24 and 42 minutes. Predict which measured duration is longer from the supplied record, then compute the relative change as (42−24)/24 = 75%. This synthetic comparison does not establish a universal shear response.

Practice questions

  1. Find the absolute change in duration.
  2. Report the change if run B is used as the reference and A as the comparison.
  3. Why should both runs use identical output intervals?

Worked answers

Answer 1

42−24 = 18 minutes.

Answer 2

(24−42)/42 ≈ −42.9%, because the denominator changes.

Answer 3

Inconsistent sampling can change measured persistence even if physical behavior is similar.
