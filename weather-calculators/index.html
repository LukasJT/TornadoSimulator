Built to actually work

These are not novelty widgets. The heat index uses the official National Weather Service Rothfusz regression, wind chill uses the 2001 NWS standard, and the humidity and dew point tools use the Magnus-Tetens equations meteorologists rely on. Where a tool is an estimate rather than an exact figure — like the snow day and sunburn calculators — the page says so plainly.
